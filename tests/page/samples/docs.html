Guide / Configuration

Configuration

Sample reads its settings from sample.config.json in the project root. Every key is optional; the defaults suit most projects.

!

Restart the development server after changing the configuration file. Changes to env are read only at start-up.

The configuration file

A minimal file sets the output folder and the base path:

{
  "outDir": "dist",
  "base": "/docs/",
  "plugins": ["sample-plugin-images", "sample-plugin-feeds"],
  "server": { "port": 4000, "open": true }
}

Keys

KeyTypeDefaultDescription
outDirstring"dist"Folder the build writes to, relative to the project root.
basestring"/"Public path the site is served from.
pluginsstring[][]Plugins to load, in order.
server.portnumber3000Port of the development server.

Plugins

Plugins extend the build. Each one is a package that exports a function returning hooks.

Images

Resizes and converts images at build time.

Feeds

Generates RSS and Atom feeds from your posts.

Search

Builds a client-side search index.

Environment variables

Variables prefixed with SAMPLE_ are exposed to pages as env.NAME. Others stay on the server.
