Inline SVG as a replaced element (sizes from width, height and viewBox,
the 300 x 150 default, CSS sizes, overflow) and its painting, and
mask-image painted through a mask group.

=== no size and no viewBox: 300 x 150
<body style="margin:0">
<div><svg id="s"></svg></div>
---
#s w=300 h=150

=== width and height attributes are presentation hints
<body style="margin:0">
<svg id="s" width="40" height="20"></svg>
---
#s w=40 h=20

=== CSS sizes win over the attributes
<body style="margin:0">
<svg id="s" width="40" height="20" style="width:10px;height:12px"></svg>
---
#s w=10 h=12

=== viewBox only: the available width, height from the ratio
<body style="margin:0">
<div style="width:200px"><svg id="s" viewBox="0 0 4 1" style="display:block"></svg></div>
---
#s w=200 h=50

=== width and viewBox: height from the ratio
<body style="margin:0">
<svg id="s" width="30" viewBox="0 0 1 2"></svg>
---
#s w=30 h=60

=== CSS width with viewBox ratio
<body style="margin:0">
<svg id="s" viewBox="0 0 2 1" style="width:50px;display:block"></svg>
---
#s w=50 h=25

=== fill: currentColor follows color, and page CSS styles the shapes
<body style="margin:0">
<style>.on { fill: #00ff00 }</style>
<svg width="40" height="20" style="display:block;color:#0000ff"><rect width="20" height="20" fill="currentColor"/><rect class="on" x="20" width="20" height="20"/></svg>

pixel 30 10 00ff00

=== use references an element elsewhere in the document
<body style="margin:0">
<svg width="0" height="0" style="position:absolute"><defs><rect id="r" width="20" height="20"/></defs></svg>
<svg width="20" height="20" style="display:block"><use href="#r" fill="#0000ff"/></svg>
---
pixel 10 10 0000ff
