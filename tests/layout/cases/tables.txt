Tables (src/layout/table.c): box tree fixup, the slot grid, the automatic
and fixed width algorithms, heights and vertical alignment, both border
models, captions, nested tables, visibility: collapse, hit testing.

Content is mostly inline-blocks (<i>, 16px tall, top aligned) so the same
cases give the same geometry in Chrome, where the expectations were
checked; cases that depend on the Ahem-like font say "no-chrome". Ahem:
16px lines.
