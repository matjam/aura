// Chrome: the image fills the 40px block at the viewBox ratio, shrinks
// to 0 in a shrink-to-fit box, fills the flex container, and takes its
// width from a set height. Without a viewBox the 300x150 default holds.
// The ::before image was drawn at the 300x150 default capped to 150
// high (Cornell's share row: an X logo 147x150 at width:12px); now it
// is 12x6 and the block is one line of the test font.

#b w=0 h=0

#h w=20 h=10
#g w=300 h=150
#p h=16
