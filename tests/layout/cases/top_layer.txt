The top layer: a dialog opened with showModal() and its ::backdrop
(HTML "the dialog element"; CSS Positioned Layout 4, section 6). Expected
values come from the specifications; Wikipedia's "Thank you for donating"
dialog painted under the footer's positioned links before.

=== a modal dialog paints and hits above later positioned content
viewport 400 300
script
<style>
body { margin: 0 }
#cover { position: relative; height: 300px; background: #ff0000 }
dialog { border: 0; padding: 0; width: 100px; height: 50px; background: #0000ff }
dialog::backdrop { background: transparent }
dialog:modal #in { background: #00ff00 }
</style>
<main><dialog id=d><div id=in style="height:20px"></div></dialog></main>
<div id=cover></div>
<script>document.getElementById('d').showModal()</script>
---
#d x=150 y=125 w=100 h=50
pixel 200 135 00ff00
pixel 200 165 0000ff
hit 200 135 #in
hit 200 165 #d
pixel 10 10 ff0000
// a transparent backdrop is still hit, and its events go to the dialog
hit 10 10 #d
